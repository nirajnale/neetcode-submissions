# 🔄 About NeetCode GitHub Sync

This repository is automatically populated using the official **NeetCode GitHub Sync** integration.

### How GitHub Sync works

1. Connect your GitHub account on **NeetCode.io**
2. Every accepted submission is automatically committed
3. Past submissions can be synchronized using Bulk Sync
4. Individual submissions can also be synced manually

Because this repository is automatically maintained, new accepted solutions are added over time without manual intervention.
